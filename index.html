PortableDev Vault
앱 소개개인정보처리방침
Personal storage · Windows

필요한 자료를 보관하고,
필요할 때 다시 꺼냅니다.

PortableDev Vault는 개인 Windows PC의 선택한 자료를 본인의 Google Drive에 보관하고, 파일 백업과 복원을 돕는 개인용 도구입니다.

현재 개인용 시험 운영 중입니다. 이 웹사이트는 앱 설명과 데이터 처리방침을 제공합니다.

01

본인의 PC와 본인의 저장공간

파일 보관·불러오기·백업 작업은 사용자의 PC에서 실행됩니다. 사용자가 선택한 자료와 백업본은 연결한 본인 Google Drive에 저장되며, 열어 본 파일은 PC에 캐시될 수 있습니다.

02

용도에 맞춘 Google 접근 권한

Google 로그인은 데스크톱 앱에서 시작합니다. 앱은 drive.file 권한으로 앱이 만들었거나 사용자가 앱에 접근을 허용한 파일을 다룹니다. Drive의 모든 기존 파일에 대한 전체 접근 권한을 요청하지 않습니다.

03

보관 파일과 버전 백업

자료를 불러오는 보관 영역과, 이전 시점으로 복원하기 위한 암호화 백업 영역을 구분합니다. 파일 이동은 복사본과 실제 복원이 확인된 자료부터 단계적으로 적용하는 방식입니다. 세부 기능은 개인용 개발 과정에서 변경될 수 있습니다.

데이터 처리 안내

접근하는 데이터, 보관 위치, 권한 철회와 삭제 방법은 개인정보처리방침에서 확인할 수 있습니다.

운영 및 문의

일반 기능 문의는 앱 안내 저장소의 문의 게시판을 이용할 수 있습니다. 계정과 개인정보 관련 문의는 Google OAuth 동의 화면에 표시되는 지원 이메일로 연락할 수 있습니다.
