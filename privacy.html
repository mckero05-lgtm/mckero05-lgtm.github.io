개인정보처리방침

적용일: 2026년 10월 31일 · 대상 앱: PortableDev Vault

PortableDev Vault는 사용자의 PC에서 본인 Google Drive와 자료를 주고받는 개인용 도구입니다. 이 방침은 앱의 파일 보관·백업·복원 기능과 이 안내 웹사이트에 적용됩니다.

1. 운영 주체와 이용 범위

개인용 앱은 GitHub 계정 mckero05-lgtm에서 관리합니다. 앱의 파일 처리 작업은 사용자가 실행하는 PC에서 이루어집니다. 이 안내 웹사이트에는 파일을 업로드하거나 Google 계정으로 로그인하는 기능이 없습니다.

2. Google에서 접근하는 데이터

  • https://www.googleapis.com/auth/drive.file 권한을 사용합니다. 앱이 만들었거나 사용자가 앱에 접근을 허용한 파일과 폴더를 대상으로 합니다.
  • 대상 파일의 내용, 이름, 크기, 수정 시각, 파일 식별자와 체크섬 등 보관·검증에 필요한 메타데이터를 처리할 수 있습니다.
  • 저장공간이 충분한지 확인하기 위해 Google Drive의 전체·사용·남은 용량 정보를 확인할 수 있습니다.
  • Google이 발급한 접근 토큰과 갱신 토큰은 사용자가 승인한 연결을 유지하는 데 사용됩니다. 앱은 Google 계정 비밀번호를 받지 않습니다.

3. 데이터 이용 목적

데이터는 사용자가 선택한 자료의 업로드·다운로드, 파일 목록 확인, 캐시, 무결성 확인, 버전 백업, 복원 및 연결 오류 확인을 위해 사용합니다. 앱의 파일 처리 기능은 이 데이터를 광고, 판매 또는 AI 모델 학습을 위한 별도 전송에 이용하지 않습니다.

4. 저장 위치와 보호 방식

  • 원격 보관 자료와 백업은 사용자가 연결한 본인 Google Drive 계정에 저장됩니다.
  • 보관 영역의 파일은 일반 파일 형태로 저장될 수 있습니다. 버전 백업 영역의 데이터는 백업 도구를 통해 암호화하여 저장합니다.
  • 열어 본 파일과 복원 결과는 사용자의 PC에 저장될 수 있습니다. 캐시의 보관기간과 용량은 로컬 설정에 따릅니다.
  • 현재 Windows 구현은 인증 설정을 암호화하고, 구성 암호와 OAuth 클라이언트 정보는 Windows 사용자 프로필에 연결된 보호 기능으로 보관합니다. PC 포맷 후 복구에는 별도로 보관한 복구 정보가 필요할 수 있습니다.
  • 작업 상태와 오류 기록에는 작업 경로, 파일 이름, 시각, 처리 결과가 포함될 수 있습니다. 인증 토큰과 비밀번호를 일반 상태 보고에 표시하지 않도록 처리합니다.

5. 외부 서비스와 데이터 공유

앱의 Google 연동에는 Google의 인증 서비스와 Google Drive API를 사용합니다. 파일 처리를 위한 별도의 중앙 운영 서버를 두지 않으며, 이 안내 사이트나 공개 소스 저장소에 사용자의 보관 파일 또는 인증 정보를 업로드하지 않습니다.

사용자가 별도로 선택한 AI 도구나 다른 프로그램으로 파일을 열거나 전송하는 경우에는 해당 도구의 이용 조건과 개인정보처리방침이 추가로 적용됩니다.

이 안내 사이트는 GitHub Pages에 호스팅됩니다. 사이트 자체에 분석 스크립트나 입력 양식을 넣지 않았습니다. GitHub는 웹사이트 제공과 보안을 위해 접속 정보 등을 처리할 수 있으며, 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요.

6. 보관기간과 삭제

보관 파일과 백업은 사용자가 직접 삭제하거나 설정한 보존 정책에 따라 정리할 때까지 남을 수 있습니다. 로컬 캐시를 삭제해도 Google Drive의 원본과 버전 백업이 함께 삭제되는 것은 아닙니다. 복원한 파일, 백업본, 원본 파일의 보관 여부는 각각 확인해야 합니다.

사용자는 Google Drive에서 이 앱이 만든 파일과 폴더를 직접 삭제하고, PC의 로컬 파일·캐시·인증 설정을 정리할 수 있습니다. 필요한 백업과 복구 정보를 확인한 뒤 삭제해야 합니다.

7. 권한 철회

Google 계정의 서드 파티 연결 관리에서 PortableDev Vault의 접근 권한을 철회할 수 있습니다. 철회하면 앱의 추가 접근이 제한되지만, 이미 보관된 파일과 로컬 복사본이 자동으로 삭제되지는 않습니다.

8. Google 사용자 데이터 정책

Google 사용자 데이터는 위에 설명한 파일 관리와 앱 운영 목적에 한해 사용합니다. Google API를 통해 받은 정보의 이용 및 전달은 Google API 서비스 사용자 데이터 정책과 그 제한적 사용 요건을 따릅니다.

9. 문의와 방침 변경

일반 문의는 앱 안내 저장소의 문의 게시판에서 할 수 있습니다. 개인정보나 계정과 관련된 문의는 Google OAuth 동의 화면에 표시되는 사용자 지원 이메일로 연락해 주세요. 공개 문의에는 파일 내용이나 인증 정보를 포함하지 않아야 합니다.

데이터 처리 방식이 바뀌면 이 문서와 적용일을 갱신합니다.
